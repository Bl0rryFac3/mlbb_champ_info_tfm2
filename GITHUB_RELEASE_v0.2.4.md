# MLBB Champ Info v0.2.4

The Champ Info screen now has passive and basic attack icons for all **26 heroes** in MLBB Heroes v2.7.0. This update adds coverage for **Eudora, Julian, Popol & Kupa, Granger, Hanzo and Atlas**.

The companion uses the current descriptions from MLBB Heroes, so both cards follow the installed version's mechanics and text. When a champion has both descriptions, the screen shows five cards.

**Windows · Teamfight Manager 2 0.7.3 or newer.** Extract `mlbb_champ_info_tfm2_v0.2.4.zip` into the game's `mods` folder and enable it alongside MLBB Heroes. The matching source ZIP includes the Rust code, UI layout, localization files and icons. Build with the stable mod SDK shipped with the game.

[Original Champ Attack Info mod by shirograhm](https://github.com/shirograhm/champ_attack_info_tfm2)
